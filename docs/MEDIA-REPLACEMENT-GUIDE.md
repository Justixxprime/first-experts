# Media Replacement Guide — First Experts Logistics website

This is for whoever uploads real company photos later. No coding involved — every
slot below just needs a photo saved into the `images/` folder with the exact
filename listed. The website is already built to pick each one up automatically
once it's there.

**Format:** JPG, quality ~80%, under 400KB each if possible (keeps the site fast).
**Orientation:** all hero photos are wide/landscape — a phone photo turned sideways
works, a tall portrait photo does not (it will get cropped oddly).

name above, tell whoever maintains the site (or open each page's HTML and swap the
`background-image:url('...')` line in the `.photo-layer` / `.hero-photo` div near
the top of the page) — the layout, text and animation around it don't need to
change at all.

WHY THIS MATTERS
--------------------------------------------------------------------

Every hero photo above is currently a licensed stock photo (Unsplash — free to use,
no legal issue), chosen to match the mood of each page. They look good, but they're
not First Experts' own operations. Swapping even a few of these for real company
photography — especially the homepage hero and the About page portrait — is the
single highest-impact visual upgrade available, because it's the difference between
"a nice logistics website" and "First Experts' own website."
